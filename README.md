A simple Slackbot made for the Stardance Community Programme.

This bot is mainly an entertainment bot. It can give you some terrible dad jokes that you may or may not laugh at, along with random cat facts because... why not? :)

So the FeatUres are:
Get a random cat fact
Get a random dad joke
Get help with available commands
 How to use it?
Go to #msg-athl in Slack and use:
CommanD	What it does
/athl-help	Shows the available commands
/athl-ping	What comes after ping?!
/athl-catfact	Gives you a random cat fact
/athl-joke	Gives you a random dad joke

A Few Problems Along the Way

This project was pretty simple, but I did run into quite a few problems with the Slackbot service daemon.

After some debugging, I eventually figured out that the main issue was just a directory path problem. Once I fixed the path, everything
started working properly.
I also originally added a /athl-dogfact command, but it wasn't working properly, so I removed it. ;(
It's a small project, but it was fun to build and a good learning experience.
Hope you like it! :3
